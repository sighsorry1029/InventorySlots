# Quick-slot radial artwork

`QuickSlotsRadial.png` is the transparent white/charcoal quick-slot group icon.
It is embedded as `InventorySlots.QuickSlotsRadial.png`; the radial menu retains
the game's normal selection tint. The plugin loads it once on first display,
releases the CPU texture copy and destroys the sprite/texture on plugin teardown.

Generated with the built-in image_gen tool on 2026-11-05. The original generated
PNG was copied without image edits, preserving its alpha channel. No external
image installation or ExtraSlots dependency is required.

Generation prompt:

> Use case: stylized-concept. Asset type: a single square PNG game radial-menu icon on a genuinely transparent background, for a Valheim inventory mod's Quick Slots entry. Design a compact cluster of exactly three simple square inventory slots in one horizontal row with a bold, angular Norse-looking lightning bolt over the central slot to signal quick access. This is an icon, not a UI screenshot. Match the style of Valheim's radial pictograms: mostly solid clean WHITE shapes, thick very dark charcoal outlines and sparse charcoal interior separation, a narrow light gray outer edging. Slightly hand-drawn medieval game linework, bold simple readable silhouette at 64px. No lettering, no numbers, no circular badge, no radial wheel, no color, no gold, no gradients, no shadows, no scenery, no texture. Center the whole compact glyph in a square canvas, about 82% width, with all strokes fully inside the canvas and ample transparent padding. Flat front view; no perspective. Preserve true alpha around and between the shapes. Only one finished icon.
